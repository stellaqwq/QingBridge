# QQ 核心研发进度

当前默认路线为自研宿主适配官方 QQNT 内核，使用 `QQ_DRIVER=kernel`，不依赖 NapCat。2026-10-24 已完成官方 9.9.36-53644 的真实扫码认证、私聊文本发送终态确认及另一账号的实际消息接收；40 项测试通过。详情见 [KERNEL.md](KERNEL.md)。

2026-10-24 核查已补上联系人查询、主动 UID 解析、票据恢复与断线重连代码及模拟回归。后续仍需这些新增能力的真实账号验收、群聊实机回归、离线同步、媒体、撤回和长期重连验证。未验收能力不宣称可用。问题清单结论见 [REVIEW-2026-10-24.md](REVIEW-2026-10-24.md)。

## 旧独立网络协议路线

路线：自行实现原生网络协议，不依赖 NapCat，也不集成已有 QQ 协议库。公开协议字段来源及实际验证记录见 [NATIVE.md](NATIVE.md)。

| 阶段 | 现有实现 | 尚需完成 |
| --- | --- | --- |
| 传输 | TCP 分帧、SSO、序列匹配、QQ TEA、P-256 ECDH、TLV/Protobuf、限长与解压限制 | 真实 QQ 返回包交叉验证、密钥轮换兼容性 |
| 扫码 | 二维码申请及 PNG 校验、等待/确认/过期/取消/失败状态、账号一致性 | 匹配签名服务和手机 QQ 实机扫码；验证挑战提交 |
| 会话 | 注册确认后上线、AES-GCM 保存、D2 恢复、心跳、断线重连 | 真实票据过期与断网恢复；NT EasyLogin 刷新 |
| 收发 | 私聊/群聊文本、可解析 UID 的 @、明确 ACK、持久消息 ID 和缓存 | 真实双账号及群聊回归；离线同步、撤回 |
| 联系人 | 好友与群列表编码/解析、好友分页、UID 映射 | 真实列表验证、陌生人和群成员查询 |
| 媒体 | 明确拒绝未实现段，能力不包含图片和语音 | 上传/下载、资源有效期和实机验证 |

原生集成测试使用本地合成 QQ 协议端，经过实际 TCP、HTTP、WebSocket 和加密封包；不能替代腾讯服务端兼容性与账号实测。真实账号验收前保留 `experimental:true`。

实机验收应记录版本、首次扫码、扫码取消与过期、错账号扫码、重启恢复、断网重连、被踢下线、发送 ACK 丢失、重复推送、多群并发和消息 ID 一致性。完成后再扩大能力声明。
